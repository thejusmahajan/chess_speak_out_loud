# Satzbau-Mantra · Ich schreibe einen Brief.

Recited every day before German study. Built in five steps; each step is one A4 sheet in the same format:
**label** (underlined) → formula → sentence. The codes `[G4]` etc. point to the grammar points in the
sprint toolkit (§13), so every line has a day-sheet block behind it.

**How to learn:** one line changes one thing. Read down a family slowly and notice what moved.
★ = a line you will actually use in Schreiben or Sprechen. If time is short, learn the ★ lines first.

**Next step when:** you can say the whole current step from memory, sheet face down, twice in a row.
If that hasn't happened by the target date, start the next step anyway but learn only its ★ lines.
The exam won't wait.

**Bridge to speaking (2 min, after reciting):** replace *einen Brief schreiben* with a verb phrase
from today's Wortschatz batch (e.g. *eine Lösung finden*) and say three lines of the current step
with it.

## Step 1 · Der Rahmen: two notes for the margin

Your Step 1 sheet is correct; keep it as it is. Add two small notes:

- Next to the negation table: **kein ← ein (or no article) · nicht ← der/den.** That is why the example
  switches from *einen Brief* to *den Brief*: *Ich schreibe keinen Brief.* / *Ich schreibe den Brief nicht.*
- Next to the imperative: **ihr → Schreibt einen Brief!** (du: *Schreib!* · ihr: *Schreibt!* · Sie: *Schreiben Sie!*)

## Step 2 · Das Verb wächst

The template sentence stays the same. Only the verb part grows.

### A · Zeitformen, der Rest `[G17]`

**Futur II** (finished by a point in the future)
Subjekt + werden + Objekt + Partizip II + haben → *Ich werde einen Brief geschrieben haben.*

**Vermutung, jetzt** (*wohl* = probably)
Subjekt + werden + wohl + Objekt + Infinitiv → *Er wird wohl gerade einen Brief schreiben.*

**Vermutung, Vergangenheit**
Subjekt + werden + wohl + Objekt + Partizip II + haben → *Er wird wohl schon einen Brief geschrieben haben.*

### B · Modalverb in der Vergangenheit

**Modalverb Präteritum** (spoken too: *musste, konnte, wollte*, like *war* and *hatte*)
Subjekt + musste + Objekt + Infinitiv → *Ich musste einen Brief schreiben.*

**Modalverb Perfekt** (the modal verb stays an infinitive)
Subjekt + haben + Objekt + Infinitiv + Modalverb → *Ich habe einen Brief schreiben müssen.*

**… im Nebensatz** (*habe* jumps in front of the two infinitives)
…, Konjunktion + Subjekt + Objekt + haben + Infinitiv + Modalverb → *…, weil ich einen Brief habe schreiben müssen.*

**nicht müssen = nicht brauchen zu**
Subjekt + brauchen + kein- + Objekt + zu + Infinitiv → *Ich brauche keinen Brief zu schreiben.*

### C · Konjunktiv II, the whole set `[G4, G5]`

★ **Rat** (advice)
Subjekt + sollte + Objekt + Infinitiv → *Du solltest einen Brief schreiben.*

★ **Vorschlag** (suggestion)
Man + könnte + Objekt + Infinitiv → *Man könnte einen Brief schreiben.*

★ **Höfliche Bitte**
Könnten (Pos. 1) + Sie + bitte + Objekt + Infinitiv? → *Könnten Sie bitte einen Brief schreiben?*

**Konjunktiv II Vergangenheit**
Subjekt + hätte + Objekt + Partizip II → *Ich hätte einen Brief geschrieben.*

★ **Bedauern** (should have)
Subjekt + hätte + Objekt + Infinitiv + Modalverb → *Ich hätte einen Brief schreiben sollen.*

★ **Irreale Bedingung, jetzt** (verb, comma, verb)
Wenn + Subjekt + … + hätte, + würde + Subjekt + Objekt + Infinitiv → *Wenn ich Zeit hätte, würde ich einen Brief schreiben.*

**Irreale Bedingung, Vergangenheit**
Wenn + Subjekt + … + gehabt hätte, + hätte + Subjekt + Objekt + Partizip II → *Wenn ich Zeit gehabt hätte, hätte ich einen Brief geschrieben.*

(*Ich schriebe einen Brief* is the verb's own Konjunktiv II form. It is correct but sounds bookish; say *würde schreiben*.
Learn the own forms only for *wäre, hätte, könnte, müsste, sollte, dürfte, wollte, gäbe, käme, fände, wüsste, ließe*.)

### D · Passiv, the rest `[G6]`

★ **Passiv Perfekt** (*worden*, never *geworden*)
Subjekt + sein + Partizip II + worden → *Der Brief ist geschrieben worden.*

**Passiv Plusquamperfekt**
Subjekt + war + Partizip II + worden → *Der Brief war geschrieben worden.*

★ **Passiv mit Modalverb**
Subjekt + Modalverb + Partizip II + werden → *Der Brief muss geschrieben werden.*

**Passiv im Nebensatz**
…, Konjunktion + Subjekt + Partizip II + worden + ist → *…, weil der Brief geschrieben worden ist.*

**Zustandspassiv** (the result: the letter is finished)
Subjekt + sein + Partizip II → *Der Brief ist geschrieben.*
(Compare: *Der Brief wird geschrieben* = someone is writing it now · *Der Brief ist geschrieben* = it's done.)

### E · Zwei neue Werkzeuge

★ **Verlaufsform** (= *I am writing*; German has no -ing, so it uses *gerade* or *dabei sein*)
Subjekt + Verb + gerade + Objekt → *Ich schreibe gerade einen Brief.*
Subjekt + sein + gerade dabei, + Objekt + zu + Infinitiv → *Ich bin gerade dabei, einen Brief zu schreiben.*

**lassen** (someone else does it for me)
Subjekt + lassen + Objekt + Infinitiv → *Ich lasse einen Brief schreiben.*

**lassen im Perfekt** (like a modal verb: stays an infinitive)
Subjekt + haben + Objekt + Infinitiv + lassen → *Ich habe einen Brief schreiben lassen.*

### The three laws of Step 2 (write them in a box at the bottom of the sheet)

1. **Two infinitives at the end:** a modal verb (and *lassen* with a second verb) stays an infinitive.
   ✗ *Ich habe einen Brief schreiben gemusst.* → ✓ *Ich habe einen Brief schreiben müssen.*
2. **In a subordinate clause, *haben* goes in front of the two infinitives, not to the very end.**
   ✗ *…, weil ich einen Brief schreiben müssen habe.* → ✓ *…, weil ich einen Brief habe schreiben müssen.*
3. **In the passive Perfekt it is *worden*.**
   ✗ *Der Brief ist geschrieben geworden.* → ✓ *Der Brief ist geschrieben worden.*
